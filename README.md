# 📺 YouTube Clone

A modern, fast, and fully responsive **YouTube Clone** built with **React 19, Vite, React Router v7, and Tailwind CSS**.

This project recreates the core YouTube browsing experience with a clean interface, responsive layouts, reusable React components, and client-side navigation.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/iamsuvodevnath/youtube-clone.git
```

### 2. Navigate to the Project

```bash
cd youtube-clone
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## ⚙️ How It Works

### ⚡ Fast Development

The project uses **Vite** for a fast development experience with **Hot Module Replacement (HMR)**, allowing changes to appear instantly without requiring a full page reload.

### 🧭 Client-Side Routing

**React Router v7** is used to handle navigation between different views without full-page refreshes, providing a smooth Single Page Application (SPA) experience.

### 📱 Responsive Design

The interface is built with **Tailwind CSS** using a mobile-first approach, allowing the application to adapt smoothly to:

* 📱 Mobile devices
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop screens
